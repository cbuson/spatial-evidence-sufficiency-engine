## Description

Reproducibility package accompanying the manuscript “From incomplete spatial evidence to bounded inference: an integrative evidence-sufficiency methodology developed across four scientific applications”. The package contains the domain-neutral Python reference engine, eight unit tests, the frozen PAG-ETR M2/M4 fixture, exact-engine T-B semantic reproduction outputs, T-D structural contract-sensitivity outputs, and the supplementary methodological workbook. For the frozen fixture, the reference engine reproduces 2,759 cell-scale cases and 8,277 overall/M2/M4 cell-output comparisons with zero discrepancies. This establishes internal semantic reproducibility for one frozen gate-dominant contract and is not external validation.
